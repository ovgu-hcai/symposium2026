# Invited speaker research

`invited-speakers.json` is an internal editorial source and is not imported by the website.

- `confirmed`: may be rendered on the public Speakers page.
- `invited`: must remain unpublished until the organizer records acceptance.
- `needs-organizer-confirmation`: the person's identity is ambiguous and must be checked before publication.

The file intentionally excludes invitation email addresses because this repository is public and contact details are not required for a speaker profile. When a speaker accepts, verify their preferred name, title, affiliation, biography, portrait permission, talk title, date, and time before copying the record into the public website.
